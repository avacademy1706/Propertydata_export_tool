# Property Desk

Monorepo for the Property Desk application.

## Structure

| Folder      | Owner              | Purpose                                   |
|-------------|--------------------|-------------------------------------------|
| `frontend/` | Satyam             | UI code (pushed on `satyam-frontend`)     |
| `backend/`  | Core team          | API, database, business logic             |
| `docs/`     | Everyone           | Project documentation                     |

## Branches

- `main` — stable, reviewed code only. No direct pushes.
- `satyam-frontend` — frontend development and frontend docs.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the workflow.
